# OminiBooks (Streamlit - Free Offline)

هذا الإصدار يعمل **بدون Anthropic API Key** وبدون أي خدمة مدفوعة.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

## ماذا يفعل؟

- إنشاء مخطط فصول تلقائي من فكرة الكتاب.
- كتابة كل فصل بشكل احترافي داخل التطبيق (مجاني بالكامل).
- حفظ الكتب في المكتبة داخل الجلسة.
- تنزيل الكتاب بصيغة HTML.
